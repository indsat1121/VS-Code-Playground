# Java Playground

Use this folder for Java coding interview practice.

## Run Hello World

From the workspace root:

```bash
cd "Java Playground"
javac HelloWorld.java
java HelloWorld
```

Expected output:

```text
Hello, Java interview practice!
```

## Practice Template

For each new problem, create a new `.java` file with a matching public class name:

```java
public class TwoSum {
    public static void main(String[] args) {
        // Practice here
    }
}
```
